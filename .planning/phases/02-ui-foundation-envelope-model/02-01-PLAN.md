   - Primary palette: sunrise-gold (#F4A261), warm-sand (#FAF3E8), dusk-rose (#E07A5F), deep-terracotta (#BC6C4A), soft-sage (#9DB5A0)
   - Neutrals: warm-charcoal (#3D3A38), soft-graphite (#6B6662), muted-stone (#A8A29E), cream (#FFFEF9), light-linen (#F5F1EB)
   - Semantic: --color-success (soft-sage), --color-attention (dusk-rose), --color-love (sunrise-gold)
   - Backgrounds: --bg-primary, --bg-card, --bg-elevated
   - Text: --text-primary, --text-secondary, --text-muted
   - Typography: --font-display, --font-body, --font-mono
   - Type scale: --text-xs through --text-4xl
   - Spacing: --space-1 through --space-24 (8px base grid)
   - Animation timing: --duration-fast (150ms), --duration-normal (250ms), --duration-slow (400ms), --duration-envelope (450ms)
   - Easing: --ease-default, --ease-out, --ease-bounce

   - Font optical sizing for Fraunces

   - Background gradient treatment per design docs (radial gradients for depth)
   - Reduced motion media query that disables animations
   - Focus visible styles using sunrise-gold

<task type="auto">
  <name>Task 3: Create base UI components (Button, Typography, Card)</name>
  <files>
    - client/src/components/common/Button.tsx
    - client/src/components/common/Button.css
    - client/src/components/common/Typography.tsx
    - client/src/components/common/Typography.css
    - client/src/components/common/Card.tsx
    - client/src/components/common/Card.css
    - client/src/components/common/index.ts
  </files>
  <action>
1. Create client/src/components/common/ directory.

2. Create Button.tsx:
   - Props: variant ('primary' | 'secondary' | 'ghost'), size ('sm' | 'md' | 'lg'), children, onClick, disabled, className, type
   - Use motion.button for subtle scale animation on tap (whileHover scale 1.02, whileTap scale 0.98)
   - Import from 'motion/react', not 'framer-motion'
   - Use clsx for conditional class composition
   - All sizes must have min-height 3rem (48px) for touch targets

3. Create Button.css:
   - .btn base styles: font-family var(--font-body), font-weight 500, border-radius 0.75rem, min-height 3rem, cursor pointer
   - .btn--primary: background var(--color-sunrise-gold), color var(--color-warm-charcoal)
   - .btn--primary:hover: background var(--color-deep-terracotta)
   - .btn--secondary: transparent background, border 2px solid var(--color-light-linen)
   - .btn--ghost: transparent, no border
   - Size variants: sm (0.5rem 1rem), md (1rem 2rem), lg (1.25rem 2.5rem)
   - Disabled state: opacity 0.5, cursor not-allowed

4. Create Typography.tsx:
   - Heading component: level prop (1-4), children, className
   - Renders h1-h4 based on level
   - Text component: variant ('body' | 'small' | 'caption'), color ('primary' | 'secondary' | 'muted'), children, className

5. Create Typography.css:
   - .heading: font-family var(--font-display)
   - Size mapping: h1 -> text-4xl, h2 -> text-3xl, h3 -> text-2xl, h4 -> text-xl
   - .text--body: font-size var(--text-base), line-height var(--leading-relaxed)
   - Color classes mapping to CSS variables

6. Create Card.tsx:
   - Props: children, className, elevated (boolean), onClick
   - Simple wrapper div with conditional 'card--elevated' class
   - If onClick provided, add role="button" and tabIndex={0}

7. Create Card.css:
   - .card: background var(--bg-card), border-radius 1rem, padding var(--space-6)
   - Box shadow per design docs
   - .card--elevated: stronger shadow, bg-elevated background
   - Hover state with subtle lift (transform translateY(-2px))

8. Create index.ts barrel export:
   ```typescript
   export { Button } from './Button';
   export { Heading, Text } from './Typography';
   export { Card } from './Card';
   ```
