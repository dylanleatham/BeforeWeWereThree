**client/src/context/SignalRContext.tsx:**
- Create SignalRContext with SignalRContextValue interface
- SignalRProvider component:
  - State: connection (HubConnection | null), connectionState (HubConnectionState)
  - useEffect to negotiate and connect on mount
  - Use HubConnectionBuilder with:
    - withUrl(url, { accessTokenFactory: () => accessToken })
    - withAutomaticReconnect([0, 2000, 5000, 10000, 30000])
    - configureLogging(LogLevel.Warning)
  - Handle onreconnecting, onreconnected, onclose callbacks
  - Cleanup: stop connection on unmount

**client/src/hooks/useSignalREvent.ts:**
- useSignalREvent<T>(eventName, handler) hook
- Use ref pattern to avoid stale closures (see 03-RESEARCH.md Pattern 4)
- Subscribe on mount, unsubscribe on unmount
- Handle null connection gracefully

**client/src/App.tsx:**
- Wrap authenticated content with SignalRProvider
- Place SignalRProvider inside session check but outside route content
- Only connect when user is authenticated (session exists)

Follow 03-RESEARCH.md Pattern 3 and Pattern 4 exactly. Import from '@microsoft/signalr' (not @aspnet/signalr).
