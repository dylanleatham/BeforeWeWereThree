```prisma
model WyrPrompt {
  id         String   @id @default(uuid())
  envelopeId String   @unique @map("envelope_id")
  optionA    String   @map("option_a")
  optionB    String   @map("option_b")
  createdAt  DateTime @default(now()) @map("created_at")

  envelope   Envelope @relation(fields: [envelopeId], references: [id], onDelete: Cascade)
  votes      WyrVote[]

  @@map("wyr_prompts")
}
```

**WyrVote model:**
```prisma
model WyrVote {
  id            String   @id @default(uuid())
  promptId      String   @map("prompt_id")
  participantId String   @map("participant_id")
  choice        String   // 'option_a' or 'option_b'
  createdAt     DateTime @default(now()) @map("created_at")

  prompt        WyrPrompt   @relation(fields: [promptId], references: [id], onDelete: Cascade)
  participant   Participant @relation(fields: [participantId], references: [id])

  @@unique([promptId, participantId])
  @@map("wyr_votes")
}
```

Create comprehensive WYR type definitions:

**shared/types/wyr.ts:**
```typescript
import { z } from 'zod';

// Choice enum
export type WYRChoice = 'option_a' | 'option_b';

// Phase state machine
export type WYRPhase = 'voting' | 'waiting' | 'revealing' | 'complete';

// Prompt type (API response)
export interface WYRPrompt {
  id: string;
  envelopeId: string;
  optionA: string;
  optionB: string;
  createdAt: string;
}

// Vote result after reveal
export interface WYRResults {
  myChoice: WYRChoice;
  partnerChoice: WYRChoice;
  isMatch: boolean;
}

// Full activity state
export interface WYRState {
  prompt: WYRPrompt;
  phase: WYRPhase;
  myVote: WYRChoice | null;
  partnerVoted: boolean;
  results: WYRResults | null;
}

// API request/response types
export interface WYRPromptResponse {
  prompt: WYRPrompt;
  myVote: WYRChoice | null;
  partnerVoted: boolean;
  results: WYRResults | null;
}

export interface WYRVoteRequest {
  choice: WYRChoice;
}

export interface WYRVoteResponse {
  revealed: boolean;
  results?: WYRResults;
}

// SignalR message types (for real-time sync)
export interface WYRVoteSubmittedMessage {
  type: 'wyr_vote_submitted';
  promptId: string;
  participantId: string;
}

export interface WYRRevealReadyMessage {
  type: 'wyr_reveal_ready';
  promptId: string;
  results: WYRResults;
}

// Zod schemas for validation
export const wyrChoiceSchema = z.enum(['option_a', 'option_b']);

export const wyrVoteRequestSchema = z.object({
  choice: wyrChoiceSchema,
});

export const createWyrPromptSchema = z.object({
  envelopeId: z.string().uuid(),
  optionA: z.string().min(1).max(500),
  optionB: z.string().min(1).max(500),
});

export const updateWyrPromptSchema = z.object({
  optionA: z.string().min(1).max(500).optional(),
  optionB: z.string().min(1).max(500).optional(),
});
```

Create the complete WYR backend stack:

**server/src/db/queries/wyr.ts:**
Typed query functions (follow pattern from envelopes.ts):
- getPromptByEnvelopeId(envelopeId): WYRPrompt | null
- getPromptById(promptId): WYRPrompt | null
- getVoteForParticipant(promptId, participantId): vote or null
- getVotesForPrompt(promptId): array of votes
- createPrompt(data): WYRPrompt
- updatePrompt(id, data): WYRPrompt
- deletePrompt(id): void
- createVote(promptId, participantId, choice): vote
- Convert Prisma dates to ISO strings for API transport

**server/src/services/wyr.ts:**
WYR business logic with SignalR integration:
- getPromptState(envelopeId, participantId): Returns WYRPromptResponse with current state
  - Get prompt, check if current user voted, check if partner voted
  - If both voted, include results
- submitVote(promptId, participantId, choice): Returns { revealed, results? }
  - Use prisma.$transaction for race condition safety (see 03-RESEARCH.md)
  - Insert vote (unique constraint prevents duplicates)
  - Notify via SignalR: sendToGroup(`activity:${promptId}`, wyrVoteSubmitted)
  - If vote count >= 2, trigger reveal:
    - Build results (relative to calling participant)
    - Broadcast wyrRevealReady to group
    - Update envelope status to 'completed'
  - Return whether reveal happened

**server/src/routes/wyr.ts:**
REST endpoints with auth:
- GET /api/wyr/:envelopeId - Get prompt state (authMiddleware)
  - Returns prompt with current voting state for this participant
- POST /api/wyr/:promptId/vote - Submit vote (authMiddleware)
  - Validate body with wyrVoteRequestSchema
  - Returns { revealed, results }
- POST /api/wyr (admin) - Create prompt (adminMiddleware)
- PATCH /api/wyr/:id (admin) - Update prompt (adminMiddleware)
- DELETE /api/wyr/:id (admin) - Delete prompt (adminMiddleware)

**server/src/index.ts:**
Mount wyrRouter at /api/wyr
