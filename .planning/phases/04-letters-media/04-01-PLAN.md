<task type="auto">
  <name>Task 2: Create media service for Azure Blob Storage</name>
  <files>
    server/src/services/media.ts
    server/src/db/queries/media.ts
  </files>
  <action>
1. Install Azure dependencies:
   `npm install @azure/storage-blob @azure/identity --workspace=server`

2. Create server/src/db/queries/media.ts with typed query functions:
   - getPhotoById(id: string): Promise&lt;Photo | null&gt;
   - getPhotoByBlobUrl(blobUrl: string): Promise&lt;Photo | null&gt;
   - getAllPhotos(): Promise&lt;Photo[]&gt;
   - createPhoto(data: { blobUrl, filename, contentType, uploadedById }): Promise&lt;Photo&gt;
   - deletePhoto(id: string): Promise&lt;Photo&gt;
   Follow pattern from server/src/db/queries/wyr.ts

3. Create server/src/services/media.ts with:

   a) generateUploadSas(filename: string, contentType: string):
      - Uses AZURE_STORAGE_ACCOUNT and AZURE_STORAGE_KEY from env
      - Creates StorageSharedKeyCredential
      - Generates unique blob name: `${Date.now()}-${sanitizedFilename}`
      - Container name: 'photos'
      - Creates BlobServiceClient
      - Generates SAS token with:
        - permissions: 'cw' (create, write)
        - startsOn: now
        - expiresOn: now + 10 minutes
      - Returns { sasUrl, blobUrl, expiresAt }
      - Throws error if env vars not configured

   b) deletePhotoFromBlob(blobUrl: string):
      - Parses container and blob name from URL
      - Deletes blob from Azure Storage
      - Uses StorageSharedKeyCredential

   c) registerPhoto(blobUrl, filename, contentType, uploadedById):
      - Calls createPhoto query to record in database

   d) removePhoto(photoId: string):
      - Gets photo by ID
      - Calls deletePhotoFromBlob
      - Deletes from database

   Handle missing env vars gracefully with clear error messages.
  </action>
  <verify>
    `npm run lint --workspace=server` passes
    `npm run build --workspace=server` succeeds
  </verify>
  <done>
    Media service can generate SAS tokens for browser uploads.

  </done>

  <action>
1. Create server/src/routes/media.ts with Express router:

   a) POST /api/media/sas (auth required):
      - Body: { filename: string, contentType: string }
      - Validate with Zod (contentType must start with 'image/')
      - Calls generateUploadSas service
      - Returns { success: true, data: UploadSasResponse }

   b) POST /api/media/register (auth required):
      - Body: { blobUrl: string, filename: string, contentType: string }
      - Registers completed upload in database
      - Gets participantId from req.user
      - Returns { success: true, data: Photo }

   c) GET /api/media (auth required):
      - Returns all photos
      - Returns { success: true, data: Photo[] }

   d) GET /api/media/:id (auth required):
      - Returns single photo by ID
      - Returns { success: true, data: Photo } or 404

   e) DELETE /api/media/:id (admin required):
      - Deletes photo from blob storage and database
      - Returns { success: true, data: {} }

2. Register routes in server/src/index.ts:
   - Import mediaRouter from './routes/media.js'
   - Add app.use('/api/media', mediaRouter)

3. Use authMiddleware for auth-required routes.
4. Use adminMiddleware for admin-required routes.
5. Follow error handling pattern from wyr.ts routes.
