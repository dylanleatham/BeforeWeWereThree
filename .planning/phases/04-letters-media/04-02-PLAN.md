2. Extend client/src/services/api.ts with media functions:
   - getUploadSas(filename: string, contentType: string): Promise&lt;UploadSasResponse&gt;
   - registerPhoto(blobUrl: string, filename: string, contentType: string): Promise&lt;Photo&gt;
   - getPhotos(): Promise&lt;Photo[]&gt;
   - getPhoto(id: string): Promise&lt;Photo&gt;
   - deletePhoto(id: string): Promise&lt;void&gt;

3. Create client/src/hooks/usePhotoUpload.ts:

   Interface UploadState:
   - isUploading: boolean
   - progress: number (0-100)
   - error: string | null

   Function usePhotoUpload():
   - Maintains UploadState with useState
   - upload(file: File): Promise&lt;string | null&gt;
     - Validates file is image (file.type.startsWith('image/'))
     - Sets isUploading: true, progress: 0
     - Calls api.getUploadSas(file.name, file.type)
     - Converts file to ArrayBuffer
     - Creates BlockBlobClient from sasUrl
     - Uploads with onProgress callback that updates progress
     - Sets blobHTTPHeaders.blobContentType
     - On success: calls api.registerPhoto, returns blobUrl
     - On error: sets error message, returns null
   - reset(): clears state
   - Returns { isUploading, progress, error, upload, reset }

   Use useCallback for upload function.
   Handle upload cancellation if component unmounts.
  </action>

  </verify>
