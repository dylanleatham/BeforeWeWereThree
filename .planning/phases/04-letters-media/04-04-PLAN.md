1. Extend client/src/services/api.ts with letter functions:
   - getLetterState(envelopeId: string): Promise&lt;LetterState&gt;
   - saveLetter(envelopeId: string, content: string, photoUrl: string | null): Promise&lt;Letter&gt;
   - submitLetter(envelopeId: string): Promise&lt;{ revealed: boolean, letters?: { mine: Letter, partner: Letter } }&gt;
   - Admin: createLetterPrompt, updateLetterPrompt, deleteLetterPrompt

2. Create client/src/hooks/useAutoSave.ts:
   - Uses useDebouncedCallback from 'use-debounce'
   - State: { isSaving, lastSavedAt, error, isPending }
   - Parameters: saveFn(content: string), delay (default 1500ms)
   - useDebouncedCallback with maxWait: 5000 (force save after 5s typing)
   - save(content: string): triggers debounced save
   - flush(): immediately execute pending save
   - Return { isSaving, lastSavedAt, error, isPending, save, flush }

3. Create client/src/hooks/useLetter.ts following useWouldYouRather pattern:
   - Parameters: { envelopeId: string }
   - State: prompt, phase, myLetter, revealedLetters, isLoading, error
   - Fetch initial state from API on mount
   - Actions:
     - save(content: string, photoUrl: string | null): calls api.saveLetter
     - submit(): calls api.submitLetter, transitions to waiting/revealing
     - advance(): transitions from revealing to complete
     - retry(): refetch state
   - SignalR integration:
     - Subscribe to 'letterSubmitted' -> if not my participant, partner submitted
     - Subscribe to 'letterRevealReady' -> transition to revealing phase
     - Use useSignalREvent hook
     - Join group `activity:${envelopeId}` on mount
   - Handle isConnected from SignalR context
   - Return { prompt, phase, myLetter, revealedLetters, isLoading, error, isConnected, save, submit, advance, retry }
