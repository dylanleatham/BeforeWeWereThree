**Create `NameCard.tsx`:**
- Props: `name` (GeneratedName), `dragState` ({ x: number, y: number }), `isActive` (boolean)
- Displays: name (large, Fraunces font), origin (comma-joined array), meaning, notes
- Layout: centered card with warm aesthetic (use CSS variables from design system)
- Visual feedback during drag: subtle tilt based on dragState.x, color overlay hints
  - Dragging right: warm gold tint hint for Love
  - Dragging left: subtle fade for Nope
  - Dragging down: soft sage tint for Maybe
- Use `motion.div` for the card animation (NOT for gesture — gesture goes on wrapper)
- Card should feel substantial — good padding, readable typography, touch-friendly
- Style with CSS variables (var(--color-sunrise-gold), var(--color-warm-sand), etc.)

**Create `NameCard.css`:**
- Card styling: rounded corners, subtle shadow, warm background
- Typography: name in Fraunces display, origin/meaning/notes in Source Sans 3
- Drag state visual hints (colored overlays with opacity based on drag distance)
- Mobile-first: full card width on mobile, max-width on larger screens
- Minimum touch target 44x44px

**Create `VotingPhase.tsx`:**
- Props: `names` (NameVoteState[]), `currentIndex` (number), `onVote` (choice: NameVoteChoice) => void, `totalNames` (number)
- Uses `useDrag` from `@use-gesture/react` on a wrapper div (NOT on motion.div — see CLAUDE.md lesson about type conflict)
- Inner `motion.div` animates based on drag state with `AnimatePresence` for card exit
- Gesture detection:
  - Right swipe: Love (mx > SWIPE_THRESHOLD_PX or vx > FAST_SWIPE_VELOCITY && dx > 0)
  - Left swipe: Nope (mx < -SWIPE_THRESHOLD_PX or vx > FAST_SWIPE_VELOCITY && dx < 0)
  - Down swipe: Maybe (my > SWIPE_THRESHOLD_PX or vy > FAST_SWIPE_VELOCITY && dy > 0)
  - Use `filterTaps: true` in useDrag options
  - Determine horizontal vs vertical: `Math.abs(mx) > Math.abs(my)`
- Progress indicator: "{current} of {total}" (e.g., "3 of 10") using string constant
- Vote labels visible below card: Love (right arrow), Maybe (down arrow), Nope (left arrow) — subtle hints
- Card exit animation: fly off in direction of swipe, next card springs in
- Use `AnimatePresence` with `mode="wait"` for card transitions
- Use existing SWIPE_THRESHOLD_PX and FAST_SWIPE_VELOCITY from constants/config.ts

**Create `VotingPhase.css`:**
- Centered card container with overflow hidden
- Progress indicator styling
- Vote label hints styling (subtle, not prominent)
- Drag overlay styling for directional hints

**Create `GeneratingPhase.tsx`:**
- Simple loading state shown while AI generates names
- Warm animated content: "Discovering names for your baby..." message
- Use motion.div for a gentle pulsing or breathing animation
- Fits the "Golden Hour Intimacy" aesthetic — not a spinner, something warm
- Optional: show the user's guidance text if it was provided

**Create `GeneratingPhase.css`:**
- Centered layout

- Animation styling
