  <action>
    1. **Create query layer** at `server/src/db/queries/trivia.ts`:
    Follow the WYR query pattern exactly (`server/src/db/queries/wyr.ts`).

    - Import db from connection, Prisma types, shared types
    - `toApiQuestion(question)`: Transform Prisma TriviaQuestion to API TriviaQuestion. Cast `question.options as TriviaOption[]` (Prisma Json returns JsonValue). Convert dates to ISO strings.
    - `getQuestionsByEnvelopeId(envelopeId)`: Query TriviaEnvelopeQuestion with include question, ordered by sortOrder. Return array of questions (flattened from join table).
    - `getQuestionById(id)`: findUnique, return toApiQuestion or null
    - `getAllQuestions()`: findMany ordered by createdAt desc, map toApiQuestion. For admin content library listing.
    - `createQuestion(data: CreateTriviaQuestionRequest)`: create with validated data, return toApiQuestion
    - `updateQuestion(id, data: UpdateTriviaQuestionRequest)`: update, handle P2025 not found, return toApiQuestion or null
    - `deleteQuestion(id)`: delete, handle P2025, return boolean
    - `assignQuestionsToEnvelope(envelopeId, questionIds)`: In a transaction, delete all existing TriviaEnvelopeQuestion for this envelope, then create new ones with sortOrder = array index. Return count.
    - `reorderEnvelopeQuestions(envelopeId, questionIds)`: Same as assign but only updates sortOrder (or just reuse assign logic since it replaces all).
    - `getAnswersForEnvelope(envelopeId, participantId)`: findMany TriviaAnswer where envelopeId and participantId
    - `createAnswer(envelopeId, questionId, participantId, selectedIndex, isCorrect)`: create TriviaAnswer, return it
    - `countAnswersForEnvelope(envelopeId, participantId)`: count TriviaAnswer records

    2. **Create service** at `server/src/services/trivia.ts`:
    Follow WYR service pattern but SIMPLER (solo activity, no SignalR, no partner logic).

    - `getEnvelopeState(envelopeId, participantId)`: Get all questions assigned to envelope (via getQuestionsByEnvelopeId). Get participant's answers (via getAnswersForEnvelope). Build TriviaQuestionState[] merging questions with answers. Compute currentQuestionIndex (first unanswered). Compute allComplete. Return TriviaEnvelopeResponse. Return null if no questions assigned.

    - `submitAnswer(envelopeId, questionId, participantId, selectedIndex)`: Validate question is assigned to envelope. Check not already answered (unique constraint). Look up question to determine correct answer (find option where isCorrect === true, compare index). Create TriviaAnswer record. Check if all questions now answered. If so, mark envelope as completed via `updateEnvelopeStatus(envelopeId, 'completed')` (import from db/queries/envelopes.ts). Return TriviaAnswerResponse with isCorrect, correctIndex, explanation, isLastQuestion, envelopeComplete.

    Important: Do NOT use SignalR. This is a solo activity.

    3. **Create routes** at `server/src/routes/trivia.ts`:
    Follow WYR route pattern. All routes under /api/trivia.

    Guest endpoints (authMiddleware):
    - `GET /:envelopeId` - Get trivia state for envelope (calls getEnvelopeState)
    - `POST /:envelopeId/answer` - Submit answer (validates with triviaAnswerRequestSchema, calls submitAnswer)

    Admin endpoints (adminMiddleware):
    - `GET /admin/questions` - List all questions in content library (calls getAllQuestions)
    - `POST /admin/questions` - Create question (validates with createTriviaQuestionSchema)
    - `PATCH /admin/questions/:id` - Update question (validates with updateTriviaQuestionSchema)
    - `DELETE /admin/questions/:id` - Delete question
    - `GET /admin/envelope/:envelopeId/questions` - Get questions assigned to envelope
    - `PUT /admin/envelope/:envelopeId/questions` - Assign questions to envelope (validates with assignQuestionsSchema)
    - `PUT /admin/envelope/:envelopeId/questions/reorder` - Reorder questions (validates with reorderQuestionsSchema)

    Note: Admin routes use `/admin/` prefix to avoid collision with `/:envelopeId` param route. Place admin routes BEFORE param routes in the router.

    Export as `triviaRouter`.

    4. **Update admin reset** in `server/src/services/admin.ts`:
    - Add `const triviaAnswersDeleted = await tx.triviaAnswer.deleteMany({});` BEFORE participant deletion (step 4, after name game data deletion)
    - Add `triviaAnswersDeleted: triviaAnswersDeleted.count` to the return object
    - Update `ResetSessionResult` interface to include `triviaAnswersDeleted: number`
    - Do NOT delete TriviaQuestion or TriviaEnvelopeQuestion (admin-created content, preserved like WyrPrompts)

    5. **Mount router** in `server/src/index.ts`:
    - Import `triviaRouter` from routes/trivia.js
    - Add `app.use('/api/trivia', triviaRouter);` alongside other route mounts

    6. **Verify build**: `cd server && npx tsc --noEmit`
