    4. **Create useTrivia hook** at `client/src/hooks/useTrivia.ts`:
    Model after useWouldYouRather but dramatically simpler (no SignalR, no partner logic, no waiting phase).

    ```typescript
    interface UseTriviaProps {
      envelopeId: string;
    }

    interface UseTriviaReturn {
      questions: TriviaQuestionState[];
      currentQuestion: TriviaQuestionState | null;
      currentIndex: number;
      phase: TriviaPhase;
      selectedAnswer: number | null;    // locally selected option before submit
      isCorrect: boolean | null;        // result after submit
      correctIndex: number | null;      // correct answer index after submit
      explanation: string | null;       // explanation text after submit
      isLoading: boolean;
      error: string | null;
      selectOption: (index: number) => void;     // local selection (before submit)
      submitAnswer: () => Promise<void>;          // submit selected answer to API
      advance: () => void;                        // move to next question or complete
      retry: () => void;
    }
    ```

    State machine:
    - Load state from API on mount (getTriviaState)
    - If allComplete on load, set phase to 'review'
    - Phase 'answering': user sees question, selects option locally (selectedAnswer state), clicks Submit
    - On submit: call submitTriviaAnswer API. On success, store isCorrect/correctIndex/explanation, transition to 'revealing'
    - Phase 'revealing': show result with suspense animation (handled by component, not hook)
    - advance(): if more questions, increment currentIndex, reset selectedAnswer/isCorrect/correctIndex/explanation, set phase to 'answering'. If last question, set phase to 'complete'. Also call onComplete callback if envelope became complete.
    - Phase 'complete': warm completion screen
    - Phase 'review': read-only review of all questions and answers

    Use useCallback for submitAnswer, advance, retry. Use useRef for mountedRef pattern (per CLAUDE.md lessons learned: set true in effect body).

    Important differences from WYR hook:
    - No SignalR connection/group join/event subscriptions
    - No partner-related state (partnerVoted, isConnected)
    - No optimistic updates (answer is permanent, server is source of truth for correctness)
    - selectedAnswer is local state (option selection before submission), NOT sent until submit
    - selectOption just sets local state, submitAnswer sends to API
