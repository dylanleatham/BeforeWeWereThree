    1. **Add admin API client functions** to `client/src/services/api.ts`:
    Import types from 'shared': TriviaQuestion, CreateTriviaQuestionRequest, UpdateTriviaQuestionRequest, AssignQuestionsRequest, ReorderQuestionsRequest, TriviaEnvelopeQuestion.

    Admin trivia question CRUD:
    - `getTriviaQuestions()`: GET `/api/trivia/admin/questions`, returns `{ questions: TriviaQuestion[] }`
    - `createTriviaQuestion(data: CreateTriviaQuestionRequest)`: POST `/api/trivia/admin/questions`, returns `{ question: TriviaQuestion }`
    - `updateTriviaQuestion(id: string, data: UpdateTriviaQuestionRequest)`: PATCH `/api/trivia/admin/questions/${id}`, returns `{ question: TriviaQuestion }`
    - `deleteTriviaQuestion(id: string)`: DELETE `/api/trivia/admin/questions/${id}`, returns `{ deleted: true }`

    Admin envelope question assignment:
    - `getEnvelopeTriviaQuestions(envelopeId: string)`: GET `/api/trivia/admin/envelope/${envelopeId}/questions`, returns `{ questions: TriviaEnvelopeQuestion[] }`
    - `assignTriviaQuestions(envelopeId: string, questionIds: string[])`: PUT `/api/trivia/admin/envelope/${envelopeId}/questions`, body `{ questionIds }`, returns `{ count: number }`
    - `reorderTriviaQuestions(envelopeId: string, questionIds: string[])`: PUT `/api/trivia/admin/envelope/${envelopeId}/questions/reorder`, body `{ questionIds }`, returns `{ count: number }`

    1. **TriviaQuestionForm.tsx** - Create/edit question form:
    Props: `question?: TriviaQuestion` (for edit mode), `onSave: (data: CreateTriviaQuestionRequest) => Promise<void>`, `onCancel: () => void`, `isSaving: boolean`

    State: questionText, options array (min 2, max 4 items each with text and isCorrect), explanation (nullable string), correctOptionIndex.

    Form layout:
    - Question text: textarea, labeled, required
    - Options: Dynamic list (2-4 items). Each has:
      - Text input (labeled "Option N")
      - Radio button for "correct answer" (only one can be correct)
      - Remove button (only show if > 2 options)
    - "Add Option" button (only show if < 4 options) using Plus icon from lucide-react
    - Explanation: textarea, optional, with hint text
    - Save/Cancel buttons at bottom

    On save: Build CreateTriviaQuestionRequest from form state. Map correctOptionIndex to isCorrect on each option. Call onSave.

    If editing (question prop provided): Pre-populate form from question data. Find correctOptionIndex from options array.

    CSS: Form styling consistent with EnvelopeForm.css. Input fields with labels, warm focus states.

    2. **TriviaContentTab.tsx** - Question library CRUD:
    Fetches questions on mount via getTriviaQuestions(). Manages list state.

    State: questions array, formMode (closed | create | edit with question), isSaving, deleteConfirm (question id or null).

    Layout:
    - Header: "Trivia Questions" heading + "New Question" button (Plus icon)
    - If formMode is create/edit: render TriviaQuestionForm
    - If formMode is closed: render question list
    - Each question card shows: question text (truncated), option count, has explanation indicator
    - Edit and Delete action buttons on each card (Edit2, Trash2 icons from lucide-react)
    - Delete confirmation pattern (same as EnvelopeManager: show Confirm/Cancel buttons inline)
    - Empty state: friendly message when no questions exist

    Also includes a section for envelope assignment. Show a dropdown/list of trivia-type envelopes (fetch from existing envelope API - filter where type === 'trivia'). When admin selects an envelope, render TriviaEnvelopeAssigner for that envelope.

    To get the envelope list, reuse the existing `getEnvelopes()` API function and filter client-side for type === 'trivia'.

    CSS: List styling consistent with EnvelopeManager card list. Cards show question preview with action buttons.

    3. **TriviaEnvelopeAssigner.tsx** - Assign + reorder questions within an envelope:
    Props: `envelopeId: string, allQuestions: TriviaQuestion[]` (full library for selection)

    State: assignedQuestions (loaded via getEnvelopeTriviaQuestions), isDirty (reorder changed), isSaving.

    Load assigned questions on mount/envelopeId change.

    Layout has two sections:
    - **Assigned Questions** (top): Drag-to-reorder list using `Reorder.Group` and `Reorder.Item` from `motion/react`
      - `axis="y"`, `values={assignedItems}`, `onReorder={handleReorder}`
      - Each item: GripVertical drag handle icon, question text, X remove button
      - `whileDrag={{ scale: 1.02, boxShadow: '0 4px 12px rgba(0,0,0,0.15)' }}`
      - "Save Order" button appears when isDirty
      - Calls reorderTriviaQuestions (or assignTriviaQuestions with new order) on save

    - **Available Questions** (bottom): List of unassigned questions (filter allQuestions to exclude assigned)
      - Each shows question text + "Add" button
      - On add: call assignTriviaQuestions with current assigned IDs + new ID

    **IMPORTANT per 06-RESEARCH.md Pitfall 4:** The `value` on each `Reorder.Item` must reference the same object from the `values` array (referential identity matters). Do NOT map/transform between values and value props.

    CSS: Two-section layout. Assigned section with drag handles. Available section with add buttons. Clear visual separation.
